### ムーブコンストラクタ、ムーブ代入演算子には必ず noexcept をつける

noexcept は関数が例外をスローしないことを保証または判定する機能

#### 例外指定子としての noexcept

関数のプロトタイプ宣言や定義の後ろに付与し、その関数が「絶対に例外を外に投げない」ことをコンパイラと開発者に伝える

``` cpp
void myFunc() noexcept{
    // この関数は例外を投げない
}
```

#### 演算子としての noexcept

渡された式が例外を投げる可能性があるかどうかを、コンパイル時に判定して bool 値を返す

``` cpp
void f() noexcept{}
void g() {}     // noexcept がついていない

int main(){
    bool b1 = noexcept(f());    // true
    bool b2 = noexecpt(g());    // false
}
```

#### 使いどころ

##### 標準コンテナ(std::vector など)でのムーブ最適化

std::vector の要素が再配置されるとき、要素のムーブコンストラクタに noexcept がついているとコンパイラは安全にムーブを選択する

- noexecpt あり  高速なムーブで要素を再配置
- noexcept なし  低速なコピーが行われる
