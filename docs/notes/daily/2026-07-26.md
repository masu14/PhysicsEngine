### テンプレート構文

#### 関数テンプレート

``` cpp
template <typename T>
T add(T a, T b){
    return a + b;
}

// 使用例
add(1, 2);     // T = int
add(1.0, 2.0); // T = double
```

typename Tはclass Tに置き換え可能

#### 複数の型を受け取る

``` cpp
template <typename T, typename U>
void printPair(const T& a, cont U& b){
    // ...
}

// 使用例
printPair(10, 3.14); // T = int, U = double
```

#### クラステンプレート

``` cpp
template <typename T>
class Array {
public:
    T& operator[](std::size_t i);
};

// 使用例
Array<int> integers;
Array<double> values;
```

関数テンプレートと異なり、クラステンプレートは型を明示する

#### テンプレート引数の型推論

``` cpp
template <typename T>
void print(const T& value){
}

// 型推論
print(10);      // T = int
print(3.14);    // T = double
print<int>(10); // 明示的な型
```

#### 非型テンプレート引数

``` cpp
template <typename T, std::size_t N>
class FixedArray{
    T data[N];
};

// 使用例
FixedArray<double, 3> vector;   // T = double, N = 3
FixedArray<int, 10> values;     // T = int,    N = 10
```

型だけでなく、整数などもテンプレート引数にできる

#### ラムダ式をテンプレートで受け取る

``` cpp
template <typename Function>
void execute(const Function& function){
    function();

// 使用例
execute([]() {
    // 処理
});

// 引数をとる場合
template <typename Function>
void execute(const Function& function){
    function(10);
}

// 使用例
execute([](int i){
    std::cout << i;

```

#### const T& で受け取る

``` cpp
template <typename T>
void process(const T& value);
```

- const : 関数内で変更しない
- & : コピーせずに参照を受け取る

ラムダ式を受け取るコードでよく使う

#### 戻り値にテンプレート型を使う


## 実装とのつながり

### テンプレートとラムダ式を使った実装

```cpp
// 1次元配列の parallelFor
template <typename IndexType, typename Function>
void parallelFor(
    IndexType start, IndexType end, 
    const Function& function, ExecutionPolicy policy) {
    if (start >= end) {
        return;
    }

    for (auto i = start; i < end; ++i) {
        function(i);
    }
}

// 2次元配列の parallelFor
template <typename IndexType, typename Function>
void parallelFor(
    IndexType beginIndexX, IndexType endIndexX,
    IndexType beginIndexY, IndexType endIndexY,
    const Function& function, ExecutionPolicy policy){
        parallelFor(
            beginIndexY, endIndexY,
            [&](IndexType j){
                for(IndexType i = beginIndexX; i < endIndexX; ++i){
                    function(i, j);
                }
            },
            policy);
    }
```

2次元配列の parallelFor では functionは引数を2つとる
1次元配列の parallelFor では functionは引数を1つとるので、呼び出し時のラムダ式の引数が
> IndexType j

となっている

### パラメータパック...を使った再帰的な処理

``` cpp
// 可変長版
template <typename T, size_t N>
template <typename... Params>
void Point<T, N>::setAt(size_t i, T v, Params... params){
    _elements[i] = v;

    setAt(i + 1, param...);
}

// 固定長版
template <typename T, size_t N>
void Point<T, N>::setAt(size_t i, T v){
    _elements[i] = v;
}
```

例えば
> setAt(0, 1.0, 2.0, 3.0);

 が呼ばれたとき、

``` cpp
setAt(0, 1.0, 2.0, 3.0); // 可変長呼び出し
// ↓

// i = 0, v = 1.0, params... = 2.0, 3.0
_elements[0] = 1.0;
setAt(1 , 2.0, 3.0);　　　// 可変長呼び出し
// ↓

// i = 1, v = 2.0, params... = 3.0
_elements[1] = 2.0
setAt(2, 3.0);  　　　　　// 最後の呼び出しは固定長
```
